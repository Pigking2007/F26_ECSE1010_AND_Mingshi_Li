## How it works

Input A is connected to ui[0], and input B is connected to ui[1].
The result is available on uo[0].
The output is high only when both inputs are high.

## How to test

Test all four input combinations: 00, 01, 10, and 11.
Only when the input is 11, will the LED light up.

## External hardware

The simulation uses DIP input switch 8 and one LED.
